# СметаПро AI (демо для портфолио)

Демо ИИ-сервиса для стройки: квиз и свободный комментарий клиента проходят через многошаговый AI-конвейер на GPT и Gemini. На выходе готовая смета с рисками, заключение для клиента, оплата PDF (макет) и чат-помощник. В админке видны расход API в долларах, журнал вызовов, промты, подключения и тарифы.

## Как открыть
`index.html` двойным кликом или через любой статический хостинг (GitHub Pages). Сборка не нужна.
- `#trace` - «Как работает ИИ»: промт, вход, ответ модели, токены и стоимость каждого шага.
- `#admin` - админка.
- `#result` - сразу пример готового расчёта.

## AI-конвейер (js/data.js)
1. Разбор заявки - Gemini 2.5 Flash-Lite, JSON: условия объекта из комментария, флаги рисков, чего не хватает.
2. Расчёт по формулам - код, без нейросети (цифры не галлюцинируют).
3. Проверка инженером - GPT-5 mini (с рассуждением): риски, запас, поправки с формулой.
4. Заключение для клиента - Gemini 2.5 Flash, живой текст.
5. Контроль качества - Gemini 2.5 Flash-Lite: сверяет числа в тексте с таблицей.

## Режимы
- **Демо** (по умолчанию): ответы моделей собираются по правилам из тех же входных данных. Токены оцениваются по длине текста, стоимость считается по тарифам из админки. История за прошлые дни - пример (`mode: sample`).
- **Боевой**: в админке включить «Боевой режим» и вставить ключи OpenAI и/или Gemini. Запросы уходят прямо из браузера в `api.openai.com/v1/chat/completions` и `generativelanguage.googleapis.com` (generateContent). Токены берутся из ответа API. Если API вернул ошибку, шаг выполняется по правилам, а расчёт не ломается. Для 429 и 5xx есть повтор запроса.
  Боевой режим на настоящих ключах ещё не проверялся. Ключи хранятся в localStorage этого браузера. В рабочей версии вызовы переносятся на сервер, и ключ клиенту не виден.

## Файлы
- `js/data.js` - модели и тарифы, шаги и промты, виды работ и формулы.
- `js/engine.js` - конвейер, вызовы API, демо-ответы, журнал расходов, история-пример.
- `js/app.js` - интерфейс: квиз, прогресс шагов, трассировка, админка, чат, оплата.
- `tools/shot.js` - скриншоты для Кворка: `node tools/shot.js` → `screens/` (5 штук 1920x1280 и 3 мобильных). Использует puppeteer-core из `drop-miniapp/tools`.
- `_v1/` - первая версия демо (один файл, ИИ только имитировался текстом).

Это демо-проект: формулы упрощённые, цены тестовые, тарифы моделей нужно сверять с прайсом провайдера.
